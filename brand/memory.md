# Brand 페이지 작업 메모

> 브랜드 페이지 퍼블리싱 시 참고하는 규격/규칙 모음.

## LAYOUT AND SPACING (레이아웃 & 작업영역)

- **구성**: 헤더(H) + 메뉴 영역(M) + 작업 영역(W) + 푸터
- **너비**: Size Fixed (고정 폭) — **최적 사이즈 1440px**
- **세로 구조** (위 → 아래):
  1. **헤더(H)** : 상단 고정 영역
  2. **작업 영역(W)** : 메인 콘텐츠 영역 (페이지별 실제 내용이 들어가는 곳)
  3. **푸터** : 하단 영역
- 메뉴 영역(M)은 헤더 구성에 포함되는 네비게이션 영역.

### 페이지 생성 시 적용
- 페이지 본문은 **작업 영역(W)** 기준으로 작성.
- 콘텐츠 최대 폭은 **1440px 고정**을 기준으로 함.
